# Короткий словарь

Словарь нужен для обсуждения выбранного процесса; это не список обязательных инструментов. Основные операции и их источники разобраны в [конвейере](pipeline.md).

| Термин | Простыми словами |
|---|---|
| Фотограмметрия | Получение пространственной геометрии из изображений с разных точек |
| Feature extraction / matching | Нахождение характерных деталей и соответствий между снимками |
| SfM — Structure from Motion | Совместная оценка камер и разреженной структуры сцены |
| Bundle adjustment | Геометрическое уточнение камер и точек по согласованности проекций |
| MVS — Multi-View Stereo | Более плотное восстановление поверхности по нескольким согласованным видам |
| Depth map | Карта глубины для изображения; глубина определяется соглашением конкретного формата |
| Point cloud / облако | Координаты точек, иногда цвет, нормали и другие признаки; связной поверхности может ещё не быть |
| Sparse / dense | Разреженная / плотная реконструкция; плотность не гарантирует точность |
| Denoising / outlier removal | Снижение шума / удаление явно ошибочных точек |
| Downsampling | Прореживание для уменьшения объёма данных |
| Normal / нормаль | Направление, перпендикулярное локальной поверхности |
| Нормализация | Неоднозначный термин; приведение диапазона координат не равно оценке нормалей или масштабированию в метры |
| Registration | Совмещение разных наборов пространственных данных |
| Scaling / масштабирование | Переход к согласованному размеру по известному расстоянию или другим опорам |
| CCTag | Кодированная кольцевая мишень; центр и ID можно распознавать на кадрах |
| GCP / опорная точка | Точка с независимо известными координатами; просто наклеенная метка ещё не GCP |
| Mesh / полигональная сетка | Вершины, рёбра и многоугольные грани, часто треугольники |
| Meshing | Построение такой сетки по пространственным данным |
| Texturing | Назначение изображений поверхности для отображения внешнего вида |
| Segmentation | Разделение точек или изображений на группы; не обязательно присвоение смысла «балка» или «стена» |
| Primitive fitting | Подбор плоскости, цилиндра и другого математического примитива к данным |
| RANSAC | Метод устойчивого поиска модели среди данных с выбросами; результат зависит от модели и порогов |
| Топология | Какие грани, рёбра, вершины и тела соединены друг с другом |
| B-Rep | Граничное представление: ограниченные поверхности, рёбра, вершины и их связи; нужна корректная сборка |
| CAD | Инженерное представление и редактирование геометрии; импорт сетки в CAD не превращает её автоматически в аналитические тела |
| Параметрическая модель | Модель, которую можно пересобрать из размеров, операций и ограничений |
| STEP в нашем процессе | Обменная геометрия build123d; исходник Python с параметрами сохраняется отдельно |
| Scan-to-CAD | Перевод измеренной геометрии в CAD; не обещание полностью автоматической обработки любого объекта |
| BIM | К геометрии добавляются строительные сущности и свойства; для пилота не требуется |
| Ортофото / ортофотоплан | Геометрически исправленное фотографическое изображение; это отдельный растровый результат, не CAD-тело |
| Harness агента | Среда, в которой агент вызывает штатные команды, наблюдает результаты и управляет выполнением |

**Три различия для этого проекта:** масштаб не исправляет форму; найденная плоскость не равна конечной детали; STEP-файл не заменяет исходную параметрическую программу.
