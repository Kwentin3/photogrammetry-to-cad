Источник: [issue #6](https://github.com/Kwentin3/photogrammetry-to-cad/issues/6).
Обновлено 21 ноября 2026. Статус: **завершено, независимая приёмка PASS**.
Поставка опубликована в [PR #7 к main](https://github.com/Kwentin3/photogrammetry-to-cad/pull/7).
PR открыт и не влит; это статус публикации, а не утверждение об обновлённой main.

## Результат и границы

Агент запускает новую подходящую фото- или видеосъёмку через входные файлы и
настройки, получает проверенную плотную геометрию, проект, фактические параметры,
короткий просмотр и машиночитаемую диагностику. Имена объектов, фиксированное
число кадров и масштаб демонстрационных сцен не входят в общий код.

Один новый реальный видеоматериал может закрыть обе обязательные проверки:
новую съёмку вне трёх прежних примеров и настоящее видео → кадры → реконструкция.
Standard и Legacy сравниваются на одних кадрах при сопоставимых настройках.
CAD, выделение деталей, новая версия Meshroom и запуск всех дополнительных
режимов в этот Goal не входят. Беседка и Dice не определяют продукт.

## Владельцы и границы

| Значение | Владелец | Передаваемый контракт |
|---|---|---|
| Съёмка, кадры и происхождение | входные данные + штатный frame selector | список файлов, source hashes, параметры отбора |
| Граф, UID, команды и кэш | установленный Meshroom/AliceVision | сохранённый native проект и его outputs/statuses |
| Маски, качество, потоки, ограничения | явные настройки запуска и native параметры | обычный файл настроек/аргументы, без object-specific ветвей |
| Физическая шкала | известное расстояние/координаты и native SfMTransform | unknown / measured_baseline / marker_coords + provenance/transform |
| Диагностика | фактические native сцены и плотная геометрия | короткий JSON с registered/total, points/bbox, CCTag observations, paths |
| Исполнение и аренда | существующий runner, Vast CLI/API, карточка | deadline, адресная остановка, backup/удаление/расходы |

Тонкая обвязка только согласует эти интерфейсы. Она не заменяет native graph
planner, не сочиняет физические размеры и не объявляет недокументированный результат.

## Обязательная приёмка

1. Новый реальный материал до dense через общий запуск без правок кода под него.
2. Реальное видео до выбранных кадров и реконструкции, с происхождением.
3. Standard vs Legacy: те же кадры, раздельные outputs, геометрия/пропуски/время/
   ручные действия и решение о PDS adapter. Без обещаний физической точности.
4. Каждый объявленный готовым дополнительный режим имеет фактический запуск;
   остальные честно отмечены изученными/отложенными.
5. Новое облако открыто существующим инструментом геометрии; JSON отражает факты,
   долю камер, единицы/масштаб, CCTag, transform и точные пути артефактов.
6. Одна актуальная инструкция выбора/запуска/продолжения/диагностики, обновлённые
   README/AGENTS/контекст, проверенный backup, закрытые платные ресурсы и публикация.

Обязательных незакрытых пунктов Goal #6 нет. Слияние PR и следующий этап
геометрии/CAD — отдельные действия; физическая шкала, скрытые стороны и точность
собственной съёмки этим техническим результатом не подтверждаются.
