# Goal #4 — Meshroom 2026

Источник: [issue #4](https://github.com/Kwentin3/photogrammetry-to-cad/issues/4).
Обновлено 21 ноября 2026. Статус: **подготовка; 2026 ещё не принят как основной**.

## Результат и границы

Закреплённая готовая сборка Meshroom 2026 должна пройти реальные фото → новое
плотное облако → Open3D → параметры/явное решение → build123d/STEP; отдельно
реальный CCTag и известная виртуальная шкала до CAD. Затем она становится основной.
Исправленная база 2023.3 и её рецепт сохраняются как точка возврата.
Съёмка беседки, допуск, экономия ручного труда и видеовход остаются следующим этапом.

## Проверенное состояние

- Рабочая ветка `goal/4-meshroom-2026`, исходное дерево было чистым.
- Исправление нормали: реальный native fit с эквивалентным отрицательным уравнением
  воспроизводил ошибку a/b/c без d. Копия нормали устранила мутацию; 5 geometry tests
  проходят. Сохранённые Dice/synthetic inliers и опубликованные параметры согласованы:
  фактического смещения прошлых примеров не обнаружено, они не переписываются.
- Input preflight: 11 filesystem/CLI tests; extra/nested/missing/changed файлы
  отклоняются без удаления чужих данных. Существующие Dice20/CCTag50/synthetic10
  проверены по исходным manifest/truth. Preflight включён до graph initialization.
- Рецепт 2023.3 переведён на обычные PowerShell/Python/OpenSSH;
  политика локального клиента остаётся у среды агента. Изменённая команда runner
  требует нового JOB_DIR с сохранением native cache и прежних журналов.
- Базовая совокупная проверка: 16 tests PASS, PowerShell snippets разбираются,
  bash syntax проверен, diff чистый; персонального executor в рецепте больше нет.
- Полный runtime archive скачан и проверен 11:19 UTC. Исследуются реальные layout,
  ELF-зависимости и native интерфейсы; CUDA/CCTag на ноде ещё не проверены.
- Архив содержит версии native executables и штатные symlinks, `lib64` и
  `libCCTag.so.1.0.4`. В осмотренных ELF есть требования до GLIBC2.34,
  GLIBCXX3.4.29; это не заменяет `ldd`/нативный запуск. Выбран готовый
  Ubuntu24.04/CUDA12.8 image, digest закреплён в `configs/runtime-2026.json`.
- Минимальный native template — `photogrammetryLegacy.mgt`: новая сборка и depth
  fixes при сохранении прежней SfM/MVS-топологии. Стандартный новый photogrammetry
  существенно меняет sparse-цепочку; object pipeline добавляет нейросетевые узлы.
  Они не нужны этому ограниченному обновлению.
- Новый стандартный SfM-формат USDA читается через AliceVision, без ручного
  разбора USD-координат. Для JSON экспорта нужны явные `sift,cctag3`, для dense
  PLY — `unknown`: пустой список нового convertSfMFormat удаляет landmarks.
