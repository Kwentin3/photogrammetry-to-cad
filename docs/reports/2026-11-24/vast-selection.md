## Сверка native средств

Installed **Vast CLI 1.11.2**, `search offers --help` и исходники package сверены
с официальными [Concepts](https://docs.vast.ai/guides/concepts),
[search reference](https://docs.vast.ai/cli/reference/search-offers),
[verification](https://docs.vast.ai/host/verification-stages) и
[hosting](https://docs.vast.ai/host/hosting-overview).
Upstream HEAD при исследовании —
[`4ee6a0ad`](https://github.com/vast-ai/vast-cli/tree/4ee6a0adbe8cc4df519f8f9fc4e25b1ce370589b);
байтовое равенство local package этому HEAD не заявляется.

Нетривиальные различия включены в инструкции: RAM query GB×1000/raw MB;
`duration` search — дни/raw секунды, но `show instance` — возраст instance;
драйвер требует `570.26.0`, а `570.26` не проходит parser; `--storage` влияет
на цену и не заменяет `disk_space`. Installed CLI defaults отличаются от SDK,
поэтому описаны actual CLI defaults, а не только web-справка. Скорости — Mb/s,
тарифы — $/GB. Reliability — история доступности/состояния, не непрерывный uptime.
`disk_bw` — чтение, не весь профиль диска. Native гарантированный показатель
скорости cold start не установлен; cache/сеть/reliability гарантий не дают.

Live-проверка выявила дополнительную границу: в B поиск с `dph_total<=0.60`
и `--storage 80` вернул raw предложение с $0.62962963/ч. Проверяющий исключил
его после чтения фактической цены. В canonical порядок добавлена обязательная
сверка пересчитанного raw `dph_total` и остальных условий; одно прохождение
query не доказывает бюджетную пригодность. Причина расхождения внутри сервера
не установлена.

Private source/help evidence сохранены вне Git в рабочей папке #21; актуальность
версии и поддерживаемых полей следующего CLI нужно проверять повторно.
