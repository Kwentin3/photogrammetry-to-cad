# Просмотр настоящей геометрии и проверка итерации

Используйте исходные кадры, dense PLY, native mesh OBJ и `scene.json` **одного
запуска**. Для фото/видео без масштаба координаты остаются в единицах сцены.
Сначала откройте общие виды, затем нужный исходный кадр в полном разрешении и
превью маски из `previews/`. Команды ниже выполняются внутри обязательного
исполнителя среды; на этой Windows — owner `heavy:geometry-review`, срок 120 s,
2 GiB, один heavy. GUI, сервер и GPU для PNG не нужны.

## Повторяемые виды

В подготовленном Python из [runbook](runbook.md) должны импортироваться
`open3d`, `numpy`, `PIL`. `scripts/inspect_geometry.py` принимает произвольные
пути и имена кадров; коробка и номера кадров не зашиты в коде.

```powershell
# Пути конкретного задания вне Git. Укажите реальный Python, не предполагаемую .venv.
& $python scripts/inspect_geometry.py --cloud "$run/dense.ply" --mesh "$run/mesh.obj" `
  --scene "$run/scene.json" --frames "$frames" --view 00000.jpg --view 00108.jpg `
  --context "$run/effective-settings.json" --context "$run/project.mg" `
  --context "$frameManifest" --output-dir "$review/views" --evidence "$review/evidence.json"
```

Если native mesh ещё в cache, найдите `mesh.obj` через `mesh_export.native_path`
или `artifacts.native_mesh` в `effective-settings.json`; путь старой удалённой
ноды замените корнем проверенного backup. `scene.json` и frames могут также
лежать рядом с другим каталогом run, если это сохранённые совпадающие камеры
и кадры; такую связь подтвердите по настройкам/manifest. Приёмка #12 использует
камеры Standard #6: совпадение проверено в [отчёте](reports/2026-11-22/auto-masks.md).

Helper не определяет физический масштаб: единицы координат следуют исходному
файлу. Масштаб устанавливают отдельные scale evidence и отчёт конкретного запуска;
подпись preview не переопределяет их.

Скрипт читает реальные файлы штатным Open3D, рисует все точки и треугольники
без фильтрации и сохраняет SHA входов, параметры камеры и границы. OBJ AliceVision
для показа приведён к осям PLY через `diag(1,-1,-1)` только в памяти. Для mesh,
уже сохранённого в осях PLY, задайте `--mesh-axes ply`. Камера берётся из
соответствующего кадра `scene.json` с учётом column-major rotation AliceVision.
Не подставляйте сцену чужого пересчёта лишь потому, что имена кадров совпадают.

PNG имеют общий масштаб внутри каждого вида. Источник сверху перспективный,
геометрия ортографическая: наложением пикселей их сравнивать нельзя. Синий цвет
и затенение искусственные. Сортировка треугольников по средней глубине —
обзорный painter, а не точная проверка взаимного перекрытия поверхностей.
Несколько видов помогают найти пропуски, но не доказывают замкнутость, толщину,
точность и наличие скрытой стороны. При спорном перекрытии откройте native
геометрию в просмотрщике по [runbook](runbook.md).

JSON содержит абсолютные частные пути: оставляйте его вне Git. Для публикации
используйте только проверенные небольшие PNG и обезличенный отчёт.

## До и после

Сначала назовите наблюдаемую проблему и проверяемую гипотезу. Сохраните оригинал,
затем создайте отдельный кандидат штатной операцией. Изменение кадров или масок
требует пересчёта зависимой геометрии; нового PNG маски недостаточно.

Для локального cloud-кандидата добавьте к тому же вызову
`--compare-cloud "$candidate"`. Все панели используют общие границы с оригиналом.
При наличии отдельно сохранённых удалённых точек можно добавить
`--highlight-cloud "$removed"`: они показаны красным поверх **Before**, включая
закрытые другими точками участки. Это диагностическое выделение, не текстура.
Mesh в таком сравнении остаётся исходным и прямо так подписан: новый cloud сам
по себе не является новым mesh.

Например, штатный [statistical outlier removal Open3D](https://www.open3d.org/docs/release/tutorial/geometry/pointcloud_outlier_removal.html)
удаляет точки по средней дистанции до соседей. Кандидат создаётся обычным Python,
без нового orchestration API:

```python
import open3d as o3d
cloud = o3d.io.read_point_cloud("dense.ply")
candidate, indices = cloud.remove_statistical_outlier(nb_neighbors=20, std_ratio=2.0)
removed = cloud.select_by_index(indices, invert=True)
o3d.io.write_point_cloud("candidate-cloud.ply", candidate, write_ascii=True)
o3d.io.write_point_cloud("removed-cloud.ply", removed, write_ascii=True)
```

На Windows с Unicode-путём перейдите в каталог входа и используйте ASCII basename,
либо штатный `native_read` из helper. Этот пример не является рекомендуемым
фильтром по умолчанию: разреженный настоящий край тоже может быть удалён.
Сохраните source/settings/SHA, версию Open3D, параметры, удалённые точки и решение
оставить/отклонить. Проверяйте и исчезнувшие шумы, и потерю полезной поверхности.
Одна [реально выполненная отрицательная итерация #15](reports/2026-11-24/geometry-iteration.md)
показывает, почему уменьшение счётчика не означает улучшения.
