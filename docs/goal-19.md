# Goal #19: подготовка GPU с переиспользованием ПО

Задание: [issue #19](https://github.com/Kwentin3/photogrammetry-to-cad/issues/19).
Реальная проверка выполнена 24 ноября 2026; обе аренды удалены, backup проверен,
native ledger — **$0.101**. Поставка — [PR #20](https://github.com/Kwentin3/photogrammetry-to-cad/pull/20).
Независимая приёмка — **PASS**; реализация и отчёт опубликованы в PR #20.
В `main` поставка попадёт после его слияния.

## Результат и границы

GPU получает закреплённый Meshroom из постоянного закрытого источника владельца;
локальный workspace передаёт данные выбранного задания штатным rclone.
Источники, пути, состав, режим и параметры задаются конфигурацией и native CLI.
Свежий запуск не требует прежнего baseline. Фото/видео, продолжение и отключаемые
ML-компоненты сохраняют существующих владельцев. Новый транспорт, оркестратор,
полный dense-пересчёт, CAD и смена версии runtime в поставку не входят.

## Принятые решения

- Сначала проверен GitHub Release этого публичного репозитория. Публичный mirror
  отклонён по конкретному ограничению: actual FFmpeg содержит `--enable-nonfree`
  и `nonfree and unredistributable`. Владелец разрешил отдельный закрытый Release
  для своих запусков. Это не заключение о допустимости публичного распространения.
- Постоянный источник опубликован и проверен до аренды. Неизменённый архив:
  600156630 B, SHA256 `4ca3cfb0898b8000def4e68d513468a199b948329b63cdb6b257e427d295163b`.
  Точные Meshroom/AliceVision commits, COPYING и уведомления сохранены.
  Release immutability выключена; идентичность обеспечивается проверкой pin/SHA.
- Постоянный private locator хранится вне Git у владельца рядом с резервным
  архивом. Управляющая машина получает временную signed URL через native GitHub
  API; account token не передаётся на GPU. Рецепт — в [runbook](runbook.md).
- Runtime lock владеет версией и SHA; aria2 — доставкой/HTTP resume; существующий
  bootstrap `--archive` — установкой и reuse. Native rclone передаёт данные;
  прежние video_frames/reconstruction обрабатывают их. Нового product API нет.
- Разрешённый предел: $0.60/ч с диском, 1 час от первой попытки, $1 с трафиком,
  stop через 45 минут и 15 минут на cleanup. Смена ноды пределы не обнулила.

## Проверенное состояние

- Реальная GPU-проверка использовала commit `5c82a3a2eed73e7f7699e9faa4cd6631f7306ee4`;
  минимальные исходники проверены по SHA до распаковки. Новая поставка меняет
  конфигурацию и инструкции, сохраняя предметные скрипты и ядра.
- Первая попытка оставалась `loading` 20 минут без SSH и собственных входов;
  удалена. Замена подготовилась до SSH примерно за 92 секунды. Конкретная причина
  первого ожидания не установлена; объявленные сетевые параметры её не доказывают.
- GPU скачала 600156630 B из постоянного источника за 12 секунд с SHA; bootstrap
  занял 16 секунд. Повтор — 2 + 2 секунды, те же SHA/inode/mtime архива и установки,
  aria2 `0B/s`; probes выполнены заново. Локальной передачи runtime не было.
- Неизменённый MOV и три сохранённых JPEG — 18330339 B; с manifest — 18330995 B.
  Native Regular дал 37 кадров; Standard CameraInit/FeatureExtraction — три
  изображения и по 20000 features. Это CPU extraction на GPU-ноде, без SfM/dense/CAD.
  Новые пути и фото/видео-наборы выбраны настройками, без правки исходников.
- SFTP: 32 MiB выше cutoff, восемь потоков, совпавшие SHA; повтор пропустил оба
  завершённых файла. Прерванный файл потребовал полной повторной отправки.
  Timeout и один EOF сохранены; последовательный повтор с четырьмя потоками
  завершился, SHA совпал, открытых участников не осталось.
- Отказ HTTP дал native exit 3 и не запустил bootstrap; явный `--archive` fallback
  на уже проверенный GPU-кэш прошёл. Новая передача 600 MB локального резерва
  в этой приёмке не заявляется. Локально aria2 resume подтверждён Range/206 и SHA.
- Backup 41970320 B, SHA256
  `f8c9246f9b614ea8adad6ecb466b51a880f7005e703baf17b55957c31858c0da`:
  whole-file и все 182 payload files проверены локально до удаления GPU.
  Обе аренды отсутствуют во всех страницах API; ledger включает обе попытки,
  диск и трафик, $0.013 + $0.088 = $0.101.
- Локальные unittest: 78, OK, два пропуска необязательных PDF-проверок (нет fitz).
  Содержательная проверка, ресурсы, тайминги и ограничения — в
  [полном отчёте](reports/2026-11-24/gpu-preparation.md).

## Готовность и продолжение

Обязательные пункты #19 выполнены. Независимая сверка кандидата `23282442`
и уточнения отчёта дала PASS: повторно пересчитаны SHA backup и всех payload,
source media/features, проверены исходные runtime/SFTP logs, cleanup и ledger.
Результат опубликован в PR #20; слияние в `main` остаётся отдельным действием.
Приватные исходники, receipt, status/log и locator сохранены вне Git, GPU не требуется.
Временный task worktree удаляется после проверенного push; ветка PR сохраняется.
Следующее задание использует [skill](../.agents/skills/photogrammetry-workflow/SKILL.md),
канонический runbook и новую карточку с действующими пределами; исторический
бюджет #19 не становится разрешением новой аренды. Полный dense и CAD остаются
отдельными продуктовыми этапами.
