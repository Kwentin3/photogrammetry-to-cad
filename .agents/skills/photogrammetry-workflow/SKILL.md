# Рабочий цикл фотограмметрии

Это вход в комплект v0.1.0: skill + инструкции `docs/` + `configs/` + существующие
`scripts/` и lock-файлы зависимостей. Корень комплекта — три уровня выше каталога
skill. Сохрани эту структуру и ссылки: одного скопированного `SKILL.md` недостаточно.
Начни с README и записи **своего** задания; исторический Goal этого репозитория
не задаёт объект, число кадров, пути, доступы или бюджет новой задачи.

Документированы Windows/PowerShell/Python 3.11 для управления и Linux amd64/Bash
для native Meshroom/AliceVision; dense требует совместимой CUDA GPU. Агенту нужны
терминал и файлы, Python/shell и tools по [runbook](../../../docs/runbook.md#до-аренды-файлы-доступ-и-пределы),
доступ к съёмке, runtime и постоянному backup; при Vast — native CLI/API и SSH.
Clone не содержит частный runtime: версию/SHA бери из
[lock](../../../configs/runtime-2026.json), доступ к owner-копии получи у владельца.
Частный путь/URL задаётся вне Git [по рецепту](../../../docs/runbook.md#linux-runtime-json-и-ресурсы).
Проверенная переносимость в другую среду/агента и интеграция с Hermes не заявлены.

Skill задаёт решения и приёмку, native Meshroom/AliceVision выполняет реконструкцию,
тонкие scripts сохраняют настройки/управляют запуском, native Vast CLI/API управляет
арендой. Не заменяй этих владельцев новым оркестратором. Команды передавай штатному
ограничителю среды. Исходники, тяжёлые результаты, ключи и частные URL — вне Git.

1. **Определи нужный результат.** Используй известное из задания; уточни только
   недостающие объект/стороны, масштаб, возможность движения, камеру и дистанцию.
   Заведи вне Git копию [карточки запуска](../../../templates/run-record.md).
   Для нового задания выбери отдельный WORK и новый RUN/project; для продолжения
   восстанови прежние абсолютные пути, cwd, команды, инстанс и cache по карточке.
   Совместимость и условия `--resume` — в [runbook](../../../docs/runbook.md#наблюдение-и-продолжение).
   Если материал уже снят, сначала просмотри его и проверь оригиналы/EXIF по
   [фото-входу](../../../docs/runbook.md#вход-фотографии-или-видео); отсутствие
   меток допускает реконструкцию с неизвестными физическими единицами.
2. **Подготовь человека, если предстоит съёмка.** Выдай
   [короткую памятку](../../../docs/operator.md), PDF/форму из
    [подготовки съёмки](../../../docs/capture.md). Перед передачей сверь номера
    в PDF и форме. Выдай схему отдельных плоских мишеней с заданными расстояниями:
    одна пара для масштаба, остальные для независимого контроля. Рейка и точный
    прямоугольник не обязательны. Сохрани неизменный комплект; рабочая копия
    формы находится отдельно. Оператор подтверждает проверенную установку
    обычным сообщением либо передаёт отличающиеся фактические длины; CSV ведёт агент.
   Подбери размер колец под
   обрабатываемое разрешение и дистанцию. Проверь несколько пробных оригиналов:
   резкость, нужные стороны, ожидаемые ID штатным детектором. При неудаче назови
    конкретное исправление и повтори пробу. План не становится подтверждением
    автоматически; фиксируй способ, источник ответа и известную неопределённость.
    Печать-only не подтверждает сценовую пару. Повторный обмер уже подтверждённой
    установки не обязателен; неизвестная неопределённость не равна нулю.
3. **Выбери ветку по [карте режимов](../../../docs/meshroom-modes.md).**
   Обычная неподвижная сцена → Standard; CCTag3 → Legacy. Видео → Regular либо
   Smart по наблюдаемой траектории/смазу, затем просмотр выбранных кадров.
   Фон маскируй на нужном этапе: при движущемся объекте до камер, при обычном
   обходе dense-only сохраняет фон для камер. Стол и переворот требуют отдельной
   подготовки; карта указывает отсутствующие зависимости и границы проверки.
   Объясни выбор и одну разумную альтернативу; необязательные ML-маски отключаемы.
4. **Обработай по [runbook](../../../docs/runbook.md).**
   При сомнении в камере или сшивке используй [короткую диагностику](../../../docs/camera-sfm.md):
   сопоставь запрос, итоговый граф и результат CameraInit/SfM, различай свободное
   уточнение и блокировки. Выбирай одну попытку по наблюдаемому недостатку;
   смена модели камеры по одному названию объектива не является диагнозом.
   Перед новым вычислением сверяй реальные job/status/аренду и точные входы. Сначала существующие данные,
   runtime, project/cache. **До аренды** проверь актуальные доступы, право create/stop/destroy
   и пределы ставки, полной стоимости, времени и ресурсов своего задания;
   допуски других задач не наследуются. Новая нода требует действующих пределов; сохраняй
   карточку вне GPU сразу после create. Параметры — в файлах, исходники под пример
   не переписывай. Сохраняй cloud и native raw mesh, проект, manifest и исходные кадры.
   Перед create выбери offer по [порядку Vast](../../../docs/infrastructure.md#выбор-vast-ноды):
   обязательные условия отдельно от предпочтений, сеть/трафик в обе стороны,
   стоимость всего задания и прошлый machine_id с повторной проверкой.
   Там же — отсутствие оффера/полей, предел loading и замена с едиными сроком
   и расходами всех попыток. Query/выбор/наблюдения сохраняй в той же карточке.
   Для новой задачи следуй native runtime download и передаче нужных оригиналов
   из runbook; cache нужен при явном совместимом resume, ML — выбранным маскам.
   Private runtime URL разрешает управляющая машина; token остаётся вне GPU.
   Разделяй loading, передачу, bootstrap и обработку в карточке; примеры defaults
   не ограничивают доступные native CLI/config параметры.
   Наблюдай job/status, журналы, ресурсы и остаток срока/денег; адресную остановку
   и восстановление выполняй по runbook после проверки завершения прежних участников.
   После sparse выполни [ранний осмотр](../../../docs/runbook.md#оценка-sparse-до-dense)
   обычных точек и зарегистрированных камер до dense; продолжение или адресный
   fallback выбери по охвату и геометрии. Второй маршрут не обязателен.
5. **Открой результат по [визуальной проверке](../../../docs/geometry-review.md).**
   Смотри реальные cloud, mesh без текстуры, исходники и использованные маски с
   нескольких направлений. Проверь нужные грани/края, фон, разрывы, двойные стенки
   и ложные перемычки. Native OBJ и PLY имеют разные оси; следуй указанному
   контракту, не подгоняй их произвольным fit. Exit 0 и счётчики недостаточны.
6. **Выбери действие по конкретному дефекту.** Сохрани baseline и гипотезу;
   выполни одну соразмерную итерацию, открой сопоставимое до/после при тех же
   видах и масштабе и реши оставить либо откатить. Новые кадры/маски требуют
   пересчёта зависимой геометрии. Локальная фильтрация mesh допустима, но не
   добавляет измеренных поверхностей. Если данных нет, покажи участок и дай
   выполнимое задание досъёмки: сторона, высоты/ракурсы, зачем и что вернуть.
   Останови перебор, когда причина требует новых наблюдений или исчерпан лимит.
7. **Передай и сохрани подготовленное плотное облако.** Выбери и открой точный файл,
   свяжи его с исходниками/RUN/SHA, укажи единицы, оси/начало, масштаб и преобразования;
   неизвестное так и назови. Опиши покрытие, пропуски, пригодность для следующего
   этапа, масштабную пару и независимые контрольные размеры, если они есть.
   Сохрани настройки, полный граф, отчёт, журналы и нужные входы/cache для продолжения.
   Подготовка означает выбранный, осмотренный и объяснённый результат, а не полноту
   или доказанную метрическую точность. При очистке оставь исходное облако,
   отдельный результат и параметры; контрольные размеры не подгоняй.
   Mesh для потребителя необязателен, но native промежуточный mesh и проверки
   связности экспортов/масштаба сохраняются. CAD — следующий самостоятельный этап.
   Запиши решение по итерации и действия оператора.
   Разделяй цифровой PDF-тест, архивную съёмку и физическую проверку новой съёмки.
   Проверь backup по SHA и читаемости **до удаления GPU**. Native Vast CLI/API
   завершает аренду: destroy после сохранения, затем отсутствие своего ID на всех
   страницах inventory и charges по [runbook](../../../docs/runbook.md#backup-освобождение-аренды-и-локальный-отчёт).
   Stop оставляет платный диск. Если запуск передаётся действующим, явно назови
   владельца, состояние, расходы, deadline и следующий шаг. Оставь точку продолжения
   по карточке; без независимых замеров не обещай точность.
